## nap-xtz-server

An experimental NAPLPS/Telidon vector graphics editor that publishes to Tezos.

### Drawing Mode Controls

#### Hand Gestures
- Pointing Up: Draw line
- V for Victory: Draw fill
- 1 x Closed Fist: Toggle palette
- 1 x Thumb Up: Reset camera position
- 1 x Thumb Down: Undo
- 2 x Closed Fist: Move camera
- 2 x Thumbs Up: Mint drawing
- 2 x Thumbs Down: Clear canvas

#### Keyboard and Mouse
- Left click: Draw
- Right click: Toggle palette
- Alt + mouse drag: Orbit
- Alt + Shift + mouse drag: Pan
- Mouse wheel: Zoom
- WASD: Move camera
